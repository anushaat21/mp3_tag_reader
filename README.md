# 🎵 MP3 Tag Reader & Editor

A C-based MP3 Tag Reader and Editor that allows users to **read and modify ID3 metadata** stored in MP3 files.

##  Features

- 📖 View MP3 metadata
- ✏️ Edit MP3 metadata
- 🎵 Edit Title
- 🎤 Edit Artist
- 💿 Edit Album
- 📅 Edit Year
- 🎼 Edit Genre
- 💬 Edit Comment
- ⌨️ Command-line based interface
- 📁 Binary file handling

## Technologies Used

- C Programming
- GCC
- Linux / WSL
- VS Code
- ID3 Metadata

##  Concepts Used

- File Handling
- Binary File Operations
- Structures
- Pointers
- Strings
- Command-Line Arguments
- `fopen()`
- `fread()`
- `fwrite()`
- `fseek()`
- Error Handling
